Scoring Reference

Cornhole: Cumulative score. First to 11 wins each game. Best of 3.

Kubb: Each kubb = 1 point. King = 5 points. Max 10 per game. Best of 3.

.22 Shoot: Each player gets 5 shots. Add both players' scores.

Hatchet Throw: Each player gets 3 warm-ups, then 6 scored throws. Add both players' scores.

Bucket Golf: Under par adds points. Over par subtracts points.

Mystery Event: Trampoline toss. Add both teammates' successful throw points.
